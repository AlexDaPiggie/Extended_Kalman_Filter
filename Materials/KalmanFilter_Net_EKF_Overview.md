# KalmanFilter.net Overview

URL: https://www.kalmanfilter.net/

This is an interactive guide for EKF. Key sections include:
- **1D Kalman Filter**: State Estimation, Kalman Gain, Predict-Update cycles.
- **Multidimensional Kalman Filter**: Matrix formulations.
- **Extended Kalman Filter**: Handling non-linear state transition and measurement functions using Jacobians.

Recommended to study online to utilize the interactive graphs.
